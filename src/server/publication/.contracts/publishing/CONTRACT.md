# Publishing

Curator authority is project-scoped. It permits publication changes and artifact registration, but not operational work, topic, job or review mutations. Additional research roles must be granted explicitly. The bootstrap administrator remains the local recovery authority.

A capture records a project-scoped journal watermark and immutable source records. A scoped capture includes the project and selected source IDs; unknown or out-of-scope IDs fail. Prior snapshots remain available. Credentials and runner hashes never enter a snapshot.

Draft saves and publication commits check exact draft and release revisions. Publishing validates references, stable page links, source chronology, accepted-review currency, update corrections and figure compatibility. The validation endpoint uses the same checks as publishing. Failure leaves the published release unchanged. Imported briefs remain drafts until explicitly published.

Published updates cannot be rewritten or removed; add a correction that identifies the earlier update. Source changes do not rewrite old releases. Archived question pages remain readable. Publication history and source snapshots are retained.

Material research changes coalesce as curation obligations. Heartbeats and publication edits do not create curation loops. Publishing clears only obligations through its captured watermark; later changes remain pending. Curation does not interrupt researchers or claim to wake a model.

Checks: publication tests; real celld CLI publication, restart and backup/restore.
