# Reading research

Default navigation leads to Now, Timeline, Updates and focused question pages. Operational records live under Inspect. Main views render publication models through the fixed catalog; agent-authored scripts, HTML and arbitrary embeds are not supported.

Every figure and supported statement has a nearby source action. A source panel identifies captured evidence and links to the current operational record. Closing the panel returns focus to its trigger. A row has one primary destination. Controls are keyboard-accessible and separately named; do not nest buttons inside row links.

Keep a readable account stable when a newer release arrives. Offer an explicit refresh; distinguish live job state from the saved explanation. Refresh errors retain the last loaded account. A draft is visibly unpublished. Missing sources/media/data must stay visible rather than becoming a zero or a fabricated plot.

Plots use verified dataset values, explicit conditions and exact-value tables. Source timelines use saved timestamps. Replays preserve clip bounds and declared alignment, provide shared play/seek, and do not autoplay. Color supplements text and shape. Berkeley Mono and thin rules retain the technical-sheet language, with a single main reading direction.

Checks: Storybook production build; browser checks for navigation, source focus, Base UI keyboard controls, media, small-screen layout and refresh failures.
