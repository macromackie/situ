# Situ contracts

- [State and coordination](../src/server/.contracts/state/CONTRACT.md): atomic commands, ownership, attention, and independent evidence review.
- [Client delivery](../src/cli/.contracts/delivery/CONTRACT.md): exact retries, workspace identity, and recoverable sessions.
- [Execution boundary](../src/integrations/.contracts/execution/CONTRACT.md): captured source, Lab admission, and uncertain execution.

These describe implemented behavior. Run `mise run check`; include `SITU_LAB=/path/to/lab` for the real execution adapter check.

- [Publication vocabulary](../src/protocol/publication/.contracts/models/CONTRACT.md): small typed models and sourceable figures.
- [Publishing](../src/server/publication/.contracts/publishing/CONTRACT.md): draft/release consistency, source currency and curator obligations.
- [Evidence storage](../src/server/assets/.contracts/storage/CONTRACT.md): verified uploads, controlled media reads and retention.
- [Reading](../src/web/.contracts/reading/CONTRACT.md): stable accounts, source navigation and scientific presentation.
